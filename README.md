# Estimateur de coût d'assurance médicale

Projet 2 d'INF1007 (A2026). L'application estime le coût annuel d'une assurance
médicale à partir du profil d'une personne (âge, IMC, fumeur ou non, etc.).
Exercice pédagogique, pas une aide à la décision.

## Jeu de données

- Source : Kaggle, « Medical Cost Personal Datasets » (mirichoi0218)
  https://www.kaggle.com/mirichoi0218/insurance
- Licence : Database Contents License (Open Data Commons)
  http://opendatacommons.org/licenses/dbcl/1.0/
- 1 338 lignes, 6 colonnes d'entrée (âge, IMC, enfants, sexe, fumeur, région), cible : charges
- Aucune donnée permettant d'identifier une personne
